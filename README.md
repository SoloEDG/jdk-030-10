# 双机抬件配合工房

一个纯前端 Vue 3 + TypeScript 工具：两台小车沿各自的直线/圆弧轨迹托住同一根刚性长梁，在分段速度上限和截止时刻内，求一次两端同时到货、全程连续且梁体不碰墙/门的配合。

## 关键能力

- 直线、圆弧轨迹按弧长统一参数化为进度 `uA/uB ∈ [0,1]`。
- 刚性约束：`|P_A(uA) - P_B(uB)| = 梁长`。
- 碰撞对象是整根梁线段，而不是只检查两个端点；关键帧之间按 ≤1cm 弧长步长做连续扫掠。
- 墙边策略：
  - `graze-ok`：`净距 = 梁段-墙段距离 - 梁半径 - 墙半厚 ≥ 0`，恰好为 0 时放行；
  - `sealed`：封条边接触即失败，`净距 ≤ 0` 判碰撞。
- 在轨迹分段边界构成的进度图上做最短路，得到 6 个干净关键帧；另有 `PLAN_N=241` 的稠密单调网格求解兜底。
- 61×61 进度组合矩阵展示第一/第二窄口：绿色为存在刚性配对且可通过，红色为碰封条，黄色为侵入擦边墙，暗色为附近无刚性配对。
- “试凑各自最快一遍”复现把两端独立最优时刻硬拼到同一时钟的错误，并在第一处不可行窄口自动停下。
- 演练播放、时间轴/“手动拨到中段”、矩阵选格和最终签收都从同一个 `(uA(t), uB(t))` 状态导出。

## 本地运行

```bash
npm ci
npm run dev
```

类型检查和生产构建：

```bash
npm run typecheck
npm run build
npm run preview
```

Docker：

```bash
docker compose up --build
```

浏览器打开 http://127.0.0.1:8030 。

## 内置搬运卡的求得节拍

共同到货时间约 `20.65s`，早于甲 `25s`、乙 `24s` 的截止时刻：

| 时刻 | 甲进度 | 乙进度 | 配合 |
|---:|---:|---:|---|
| 0.00s | 0.0% | 0.0% | 起托 |
| 2.50s | 19.7% | 19.7% | 同步直推 |
| 8.94s | 52.7% | 19.7% | 乙在弧心等待，甲转过四分之一弧 |
| 12.52s | 85.6% | 52.5% | 平梁同步横移，通过第一横缝 |
| 18.96s | 85.6% | 85.6% | 甲在弧心等待，乙转回竖直梁 |
| 20.65s | 100% | 100% | 同时签收 |

核心代码在 `src/features/lift/lib/`，界面在 `src/features/lift/ui/` 与 `src/app/Workspace.vue`。
